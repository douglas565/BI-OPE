# Regras OPE
Conforme Plano de Migração:
1. **Disponibilidade**: (Tempo Base - Paradas) / Tempo Base
2. **Performance**: (Meta de Tempo * Validos) / Tempo Disponível
3. **Qualidade**: Validos / Realizados
4. **OPE**: Disponibilidade * Performance * Qualidade

Equipes CCO são excluídas de todos os cálculos.
A Data Operacional de um turno da madrugada (antes das 06:30) é alocada no dia anterior.
